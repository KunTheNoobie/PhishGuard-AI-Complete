## Appendix B: FastAPI Asynchronous Route Implementation Snippet

The following Python codebase snippet demonstrates the core asynchronous endpoint implementation utilizing the FastAPI framework. This code illustrates the practical application of ASGI concurrency principles discussed in Chapter 4 and 5. It highlights the use of Pydantic models for strict payload validation and the utilization of `asyncio.gather()` to ensure that the GPU-bound BERT inference and the CPU-bound Regex database queries execute concurrently on separate worker threads without locking the main event loop.

```python
"""
PhishGuard-AI: Asynchronous Multi-Modal Threat Orchestrator
Author: Liew Yi Ler (Student ID: 25WMR09747)
Module: Semantic Threat Intelligence and Mule Account Verification Engine
"""

from fastapi import APIRouter, HTTPException, Depends, BackgroundTasks
from pydantic import BaseModel, HttpUrl
import asyncio
import logging
import time

# Import internal modular services
from services.nlp_engine import predict_semantics
from services.mule_scanner import extract_and_verify_mules
from core.security import verify_api_key
from database.repository import log_threat_telemetry

router = APIRouter()
logger = logging.getLogger(__name__)

# Pydantic Schema for strict JSON payload validation
class WebPayload(BaseModel):
    url: HttpUrl
    dom_content: str

@router.post("/api/v1/analyze/semantics", status_code=200)
async def analyze_web_payload(
    payload: WebPayload,
    background_tasks: BackgroundTasks,
    api_key: str = Depends(verify_api_key)
):
    try:
        start_time = time.perf_counter()
        
        # Step 1: Initialize concurrent background tasks via asyncio.create_task()
        # Prevents the Regex engine from blocking the Deep Learning tensor operations.
        semantic_task = asyncio.create_task(
            predict_semantics(str(payload.url), payload.dom_content)
        )
        mule_task = asyncio.create_task(
            extract_and_verify_mules(payload.dom_content)
        )

        # Step 2: Await the completion of both parallel tasks simultaneously via asyncio.gather().
        semantic_result, mule_result = await asyncio.gather(
            semantic_task, mule_task
        )

        # Step 3: Trigger Background Task for Threat Telemetry Logging (Non-Blocking)
        if semantic_result.get("is_malicious") or mule_result.get("mule_detected"):
            background_tasks.add_task(
                log_threat_telemetry, 
                str(payload.url), 
                semantic_result.get("confidence", 0.0),
                "BLOCK_RENDER"
            )

        total_latency_ms = round((time.perf_counter() - start_time) * 1000, 2)

        # Step 4: Orchestrate and return the unified JSON response
        is_threat = semantic_result.get("is_malicious") or mule_result.get("mule_detected")
        
        return {
            "meta": {
                "transaction_id": "0ccbd126-85bb-4db0-8e08-2bd9066466a8",
                "processing_time_ms": total_latency_ms
            },
            "data": {
                "semantic_analysis": semantic_result,
                "mule_scan": mule_result
            },
            "orchestration": "BLOCK_RENDER" if is_threat else "SAFE"
        }

    except ValueError as val_err:
        logger.error(f"Validation Error: {val_err}")
        raise HTTPException(status_code=422, detail=f"Unprocessable Entity: {str(val_err)}")
    except Exception as e:
        logger.critical(f"Inference Engine Failure: {e}")
        raise HTTPException(status_code=500, detail="Internal Server Error: AI inference failed.")
```
